Empty batches in 2D Crop and Resize operations now follow the sampled batch-wide application decision, instead of always retaining the input size when `p < 1`. Images, tensor masks, downstream shape history and saved-parameter replay share that decision, including in `VideoSequential`. Selected empty slice crops retain the input gradient connection. Older saved params without the new private metadata retain the previous fallback; static `p=1` behavior is unchanged. Part of #4429.
